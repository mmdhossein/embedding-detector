# Intent Detection with Sentence Embeddings

A lightweight, embedding-based intent classifier that replaces keyword matching with semantic similarity using sentence transformers. The system encodes representative examples for each intent category, computes their mean embeddings, and classifies incoming messages by cosine similarity with a configurable threshold to reject unrelated inputs. Originally built for Persian/English service intent detection (tax, military, insurance, traffic, judicial, subsidy, profile queries), this approach generalizes to any classification task where semantic meaning matters more than exact keyword matches. Other use cases include customer support ticket routing (billing, technical, sales), content moderation (spam, abuse, benign), FAQ matching, email categorization, sentiment-based triage, product review classification, or any domain where you have labeled examples and need fast, interpretable semantic classification without fine-tuning a full model.
There is also tf-idf + SVM sentence detector which works pretty fast as a ML solution but it lacks the precision in the embedding.

Another embedding + neural network implementation was a Persian service intent classification pipeline using a hybrid NLP approach that combines **Sentence-Transformers embeddings** with a **PyTorch neural network classifier**. It generates a synthetic dataset across 7 service domains—**insurance, judicial, military, profile, subsidy, tax, and traffic**—then preprocesses Persian text, converts each message into a **384-dimensional semantic embedding** using `all-MiniLM-L12-v2`, and trains a feed-forward neural network to predict the correct intent. The pipeline includes **train/test splitting, AdamW optimization, cosine learning-rate scheduling, early stopping, full evaluation metrics, model serialization, reload verification, demo inference, and comparison against a keyword-based baseline**. For production use, it wraps the frozen encoder and trained classifier in an `IntentPredictor` that supports both **top-intent prediction** and **confidence-scored inference with unknown intent rejection** via a configurable threshold.
